# pome — ポメラ風コマンドラインエディタ

King Jim ポメラ DM250 の内蔵エディタの外観・操作性を参考にした、
curses ベースの軽量日本語テキストエディタです。
Debian bullseye を導入した DM250 上での執筆を想定しています。

- **Python 3 標準ライブラリのみ**（追加パッケージ不要、単一ファイル）
- 起動すると**前回開いていたファイルをそのまま開く**（ポメラ流「開けばすぐ書ける」）
- **Esc でプルダウンメニュー**（ファイル / 編集 / 検索 / ツール / ヘルプ）
- 下部ステータスバーに**行・桁・総文字数**を常時表示
- **文字数カウント**（改行含む/含まず・行数・原稿用紙換算）
- 全角/半角混在の**折り返し表示（簡易禁則処理つき）**
- **自動保存**（3秒アイドルで保存。ON/OFF切替可）
- **保存履歴から復元** — 自動保存前の原稿も残し、終了後に戻せます
- **Git プル/プッシュ**をメニューから実行（QR送信の代替）
- ポメラからの持ち込みファイル対応：**Shift-JIS(cp932)・CRLF を自動判別し、保存時も維持**
- Python例外を捕捉した場合は未保存内容を `～.rescue` に退避（電源断などは対象外）

## pome を中心にした執筆環境（v1.1）

文字キーはそのまま入力になります。Vim のような挿入／ノーマルモードの切り替えはありません。
Debian の Python 3 と curses が使える日本語端末で、次の手順を実行してください。
追加の Python パッケージや管理者権限は不要です。

```sh
cd /path/to/pome
sh install.sh
. "$HOME/.local/share/pome/writing-env.sh"

mkdir -p "$HOME/原稿"
write "$HOME/原稿/作品.txt"
```

`write` だけで前回の原稿を再開します。`pome 原稿.txt` でも同じエディタを起動できます。
新しい原稿は上のように**最初から保存先を指定**すると、入力後3秒で自動保存されます。
初回にファイル名なしで起動した場合や「新規作成」の無題原稿は、まず Ctrl+S で保存先を指定してください。

設定を読み込んだシェルでは `EDITOR` と `VISUAL` も `pome` になります。
`pomeweb` のフォーム編集など、これらの変数を利用するツールからも起動できます。
`pomeweb` の設定で `editor` を明示している場合はそちらが優先されるので、`"editor": "pome"` に変更します。
シェル設定やVim設定は自動変更しません。毎回有効にする場合は、上の `. .../writing-env.sh` の行を
利用中のシェルの起動設定に追加してください。試用を終えるには、設定を追加していない新しい端末を開きます。

インストール先は既定で `~/.local`。独自の場所を使う場合：

```sh
POME_PREFIX="$HOME/apps/pome" sh install.sh
export POME_PREFIX="$HOME/apps/pome"
. "$POME_PREFIX/share/pome/writing-env.sh"
```

再度 `sh install.sh` を実行するとこの版へ更新できます。既存の無関係なコマンドや、導入後に手動編集したファイルがあれば上書きせず中止します。
同名のシステムコマンド `write` がある場合、この設定を読み込んだシェルでは執筆用の `write` が優先されます。
`dotfiles/pomera/pome.py` は別コピーです。この版を使う際は、このリポジトリから導入してください。

## 誤操作したとき

編集中なら **Ctrl+Z** で取り消せます。保存・自動保存した後でも取り消せます。
v1.1 では、保存後の取り消しが誤って「保存済み」になっていた不具合を修正しました。

終了してしまった場合は、同じ原稿を開いて次の手順で復元します。

1. Esc →「ファイル」→「保存履歴から復元...」を選ぶ。
2. 新しい順の履歴一覧で日時と番号を確認し、Enterで一覧を閉じる。
3. 番号を入力して、復元内容のプレビューを確認する。
4. `y` で本文に復元する。Escなら中止。復元後は Ctrl+Z で取り消すこともできる。
5. Ctrl+Sで保存する。自動保存がONなら3秒の待機後に保存される。

履歴は上書き前の元データを、`~/.local/state/pome/history/` の原稿パス別ディレクトリに保存します。
自動保存でも履歴を作り、文字コード・改行を含む元ファイルのバイト列を保持します。
`XDG_STATE_HOME` を指定している場合は `$XDG_STATE_HOME/pome/history/` です。
原稿を移動すると履歴の対応先が変わるため、移動前に必要な履歴を復元してください。
履歴を保存できなければ原稿の上書きも中止します。別のプログラムで原稿が変更・削除されていた場合も
上書きせず、「名前を付けて保存」で現在の内容を退避できるようにします。
自動保存が失敗した場合は警告の連続表示を避けるため一時停止し、手動保存の成功後に再開します。

履歴は自動削除しません。長く使うと容量が増えるため、必要な履歴を別媒体へ保管してから整理してください。
これは保存した版の履歴であり、まだ保存していない入力、電源断、ディスク故障、同時書き込みの完全な保護ではありません。
大切な原稿は別媒体にもバックアップしてください。

## キー操作

| キー | 動作 |
|---|---|
| Esc | メニューを開く / 選択解除 |
| Ctrl+S | 上書き保存 |
| Ctrl+O / Ctrl+N | 開く / 新規作成 |
| Ctrl+Q | 終了 |
| Ctrl+Z / Ctrl+Y | 元に戻す / やり直し |
| Ctrl+Space | 選択開始（カーソル移動で範囲を広げ、Escで解除） |
| Ctrl+X / C / V | 切り取り / コピー / 貼り付け |
| Ctrl+A | すべて選択 |
| Ctrl+F | 検索（Ctrl+L 次を検索、Ctrl+E 前を検索） |
| Ctrl+R | 置換（1件ずつ確認 / まとめて置換） |
| Ctrl+G | 指定行へジャンプ |
| Ctrl+W | 文字数カウント |
| Ctrl+T | 日時を挿入 |
| Home / End / PgUp / PgDn | 行頭 / 行末 / ページ移動 |

Shift+矢印での範囲選択にも対応しています（端末が対応している場合）。

## Git 連携（iPhone テザリング + GitHub）

メニューの「ツール」から実行します。

- **Git プル（受信）**: `git pull --ff-only` を実行し、開いているファイルを読み直します
- **Git プッシュ（送信）**: 保存 → `git add` → `git commit` → `git push` を一括実行します
- **Git 状態表示**: ブランチ・変更・直近のコミットを表示します

事前に一度だけ、原稿ディレクトリをリポジトリにしておきます。

```sh
cd ~/原稿
git init -b main   # 既存リポジトリを clone してある場合は不要
git remote add origin git@github.com:あなたのID/リポジトリ名.git
git config user.name "あなたの名前"
git config user.email "you@example.com"
```

テザリング環境ではSSH鍵認証が確実です（パスワード入力画面が出るとエディタ上では操作できないため）。

```sh
ssh-keygen -t ed25519 -N ""    # 鍵を作り、~/.ssh/id_ed25519.pub を GitHub に登録
ssh -T git@github.com          # 一度接続確認しておく
```

通信のタイムアウトは既定180秒です（設定ファイルで変更可）。

## 設定ファイル

`~/.config/pome/config.json`（`XDG_CONFIG_HOME` 指定時はその下の `pome/config.json`）に保存されます（メニューから切り替えた内容も反映）。

```json
{
  "ambiguous_wide": true,      // ※や○など曖昧幅文字を全角として扱う
  "autosave": true,            // アイドル時自動保存
  "autosave_idle_sec": 3.0,
  "tab_width": 4,
  "undo_limit": 200,
  "git_timeout_sec": 180,
  "last_file": ""              // 前回開いていたファイル（自動更新）
}
```

## 表示が崩れるときは

日本語コンソール（fbterm / kmscon 等）の**曖昧幅文字の扱い**とpomeの設定を
合わせてください。記号（※ ○ ─ など）の位置がずれる場合：

- fbterm を `--ambiguous-wide` で起動しているなら pome も `ambiguous_wide: true`（既定）
- 端末側が半角扱いなら、メニュー「ツール → 曖昧幅文字 全角/半角」で半角に切り替え

日本語入力は uim-fep や fcitx5 など、端末に確定文字列を送る方式のIMEで動作します。

## ポメラ内蔵エディタとの違い（既知の制限）

- QRコード送信機能はありません（Git 連携で代替）
- 縦書き表示・アウトライン・カレンダーはありません
- 検索・置換は改行をまたぐ文字列には対応していません
